# Gokyo Bistro Management System

## Description
A restaurant management system proposed as part of my second-year Software Engineering coursework. The project applies **Agile Scrum methodology** to plan a solution for table reservations, online payments, food and beverage ordering, home delivery, billing, menu management, and customer feedback. It demonstrates software engineering practices through requirements analysis, UML modelling, object-oriented design, system architecture, sprint planning, and UI/UX prototyping.

## Key Features
- User registration, login, and password recovery.
- Table availability checking, reservations, advance payments, and cancellations.
- Food and beverage ordering with optional home delivery.
- Menu management, billing, and receipt generation.
- Financial reporting, proposed revenue prediction, and menu recommendations.
- Promotional offers, customer ratings, and feedback management.

## Methodology: Agile Scrum
The project is organised into four planned sprints:

1. **Sprint 1:** Authentication and registration.
2. **Sprint 2:** Table booking and reservation management.
3. **Sprint 3:** Payments, food ordering, and delivery.
4. **Sprint 4:** Administration, reporting, offers, and feedback.

The project plan uses a Work Breakdown Structure (WBS) and Gantt chart to organise tasks, milestones, dependencies, and the development timeline.

## System Analysis and Design
- Use Case Diagram and expanded use case descriptions.
- Collaboration Diagram and Activity Diagram.
- UML Analysis Class Diagram and domain class mapping.
- Three-tier architecture: presentation, application, and data.
- Object-oriented relationships: inheritance, association, aggregation, and composition.
- **16 UI/UX wireframe prototypes** created using Draw.io.

## Design Patterns
- **Model-View-Controller (MVC):** Separates application data, interface, and control logic.
- **Factory Pattern:** Supports the creation of different payment types.
- **Singleton Pattern:** Provides a shared database connection object.

## Proposed Technology Stack
- **Frontend:** HTML, CSS, JavaScript, React (proposed).
- **Backend:** Java with a web framework or PHP as an alternative.
- **Database:** MySQL.
- **Tools:** Visual Studio Code, Git, GitHub, Postman, Draw.io, and TeamGantt.

## Testing and Maintenance
The proposed testing plan covers unit, integration, system, and user acceptance testing, alongside black-box and white-box testing. The maintenance strategy addresses corrective, adaptive, perfective, and preventive maintenance.

## Project Scope
This repository documents the project's **software engineering analysis, design, Agile Scrum planning, and UI/UX prototypes**. The technology stack and implementation approach are proposed; the coursework does not represent a claim that the complete application has been developed or deployed.
